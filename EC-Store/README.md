# Shah Clothing Store

A modern e-commerce clothing store built with React.js, featuring product browsing, category-based navigation, product details, and shopping cart functionality.

##  Features

- Browse clothing across different categories
- View individual product details
- Select product sizes
- Add items to the shopping cart
- Update quantities and remove items from the cart
- Responsive user interface

##  Tech Stack

- React.js
- JavaScript
- Tailwind CSS
- React Router
- Context API for cart state management
- Vite

##  Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/sumit-dev77/shah-clothing-store.git
   ```

2. Navigate to the project folder:

   ```bash
   cd shah-clothing-store
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
